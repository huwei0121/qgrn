The public numerical module preserves the author's function correspondence and
update order while replacing MATLAB global state with an explicit Python object.
Indices become zero based; column-major controls and masks remain unchanged.
The full grid is unchanged. The selected mathematical abs-trace gradient corrects
the original derivative convention explicitly. BFGS uses the independent public
mathematical implementation in bfgs.py, not MATLAB P-code. Krotov updates retain
the original sequential update mechanism. Graphics, audio, demo scripts, and
workspace management are not required by these nine benchmark models.
