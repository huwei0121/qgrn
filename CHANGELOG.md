# Changelog

## 0.1.0

- Structured gradient-regularized Gauss-Newton solver with residual and constrained oracle interfaces.
- Sparse affine geometry, hardware-bound directions, and adaptive regularization.
- Nine quantum-control models with native Ipopt/MadNLP interfaces and documented BFGS/Krotov implementations.
- Ten random seeds per problem, paired inputs, recorded curves, and reproduction commands.
- Standalone X-gate example, API documentation, numerical tests, and distribution checksums.
